========================================
18. TẠO GIT REPOSITORY
========================================

Có 2 cách tạo Git Repository:

1. Có project sẵn trên máy
----------------------------------------
git init

=> Tạo thư mục .git
=> Biến project thành Git Repository


2. Có repository trên GitHub
----------------------------------------
git clone <repo-url>

=> Download source code về máy
=> Tự động cấu hình remote origin


========================================
PHẠM VI GIT REPOSITORY
========================================

my-project/
│
├── .git/       (Git metadata)
├── README.md
├── app.js
├── src/
│   └── style.css
└── docs/
    └── guide.md

git init thực hiện tại thư mục TOP LEVEL

Git sẽ quản lý:
✔ README.md
✔ app.js
✔ src/*
✔ docs/*

Nguyên tắc:

- Git theo dõi toàn bộ file/folder bên trong thư mục chứa .git
- Thư mục cha KHÔNG được theo dõi
- Thư mục con sẽ được theo dõi
- .git là trái tim của repository

===============================================================================
                       GIT & GITHUB INTERVIEW CHEAT SHEET
                       Tong Hop Cac Lenh Da Hoc & Cac Loi Thong Dung
===============================================================================

-------------------------------------------------------------------------------
PART 1: QUY TRINH LUU TRU VA DONG BO CODE (3 BUOC THAN CHU)
-------------------------------------------------------------------------------
Moi khi thay doi noi dung file, tao file moi va an Ctrl + S, hay thuc hien:

1. Kiem tra trang thai hien tai cua thu muc:
   $ git status
   -> Y nghia: Xem cac file nao da bi thay doi (mau do) hoac chua duoc theo doi.

2. BUOC 1: Dua file vao Vung cho (Staging Area)
   $ git add .
   -> Y nghia: Gom TAT CA cac file thay doi de chuan bi dong goi.
   -> Luu y: Bat buoc phai co dau cach (khoang trang) tuong ung truoc dau cham.

3. BUOC 2: Chinh thuc luu lai vao lich su Local (Commit)
   $ git commit -m "Noi dung ghi chu ngan gon"
   -> Y nghia: Tao mot phien ban luu tru tren may ca nhan kem loi nhan giai thich.

4. BUOC 3: Day code tu may ca nhan len mang (GitHub)
   $ git push origin main
   -> Y nghia: Dong bo nhanh 'main' tu local repository len remote repository 'origin'.

-------------------------------------------------------------------------------
PART 2: CAC LENH HO TRO KHAC DA DUNG
-------------------------------------------------------------------------------
* Khoi tao hoac lam moi Git Repository tai thu muc hien tai:
  $ git init
  -> Khi chay lai tren thu muc da co Git, se bao: "Reinitialized existing Git repository..."

* Huy bo cac thay doi cua mot file, dua ve trang thai cu:
  $ git restore <ten_file>

-------------------------------------------------------------------------------
PART 3: CAC LOI THUONG GAP (CAU HOI PHONG VAN THUC TE)
-------------------------------------------------------------------------------

LOI 1: Git bao file bi "modified" du da doi ten hoac bam Ctrl + S nhung tinh trang van do.
- Nguyen nhan: Do Windows mac dinh an duoi mo rong (.md, .txt). Khi bam F2 sua 
  "README.md" thanh "README.txt", thuc chat ten file bien thanh "README.txt.md".
- Cach fix: Vao View trong Windows Explorer -> Tich chon "File name extensions" -> 
  Xoa bo duoi .md bi an di.

LOI 2: git: 'add.' is not a git command. See 'git --help'.
- Nguyen nhan: Viet lien tu "add." khong co dau cach. Git hieu lam 'add.' la mot lenh.
- Cach fix: Viet dung cu phap co dau cach: git add .

LOI 3: bash: warning: command substitution: ignored null byte in input
- Nguyen nhan: Khi mo Git Bash, he thong doc Bien moi truong Windows (PATH) hoac 
  file cau hinh (.bashrc) bi dinh ky tu trong (null byte) hoac loi dinh dang (;;).
- Cach fix: Vao Edit the system environment variables -> Environment Variables -> 
  Kiem tra bien Path -> Xoa dong trong hoac dau phan tach bi loi.

-------------------------------------------------------------------------------
PART 4: KIEN THUC PHONG VAN CAN NHO (CORE CONCEPTS)
-------------------------------------------------------------------------------
* Mo hinh 3 vung lam viec cua Git:
  1. Working Directory: Thu muc lam viec tren may (Noi ban go code, file mau do).
  2. Staging Area: Vung cho (Sau khi `git add .`, file chuyen sang mau xanh).
  3. Local Repository: Kho luu tru tren may (Sau khi `git commit`, file duoc dong goi).
  4. Remote Repository: Kho luu tru tren mang nhu GitHub/GitLab (Sau khi `git push`).

* Phan biet `git add` va `git commit`:
  - `git add` la hanh dong xep do vao thung hang (chuan bi).
  - `git commit` la hanh dong niem phong thung hang va danh ma so phien ban (chinh thuc luu).

========================================
CLONE REPOSITORY QUA SSH
========================================

Điều kiện:

✔ Đã cài Git
✔ Đã tạo SSH Key
✔ Đã add SSH Public Key lên GitHub

----------------------------------------
1. Kiểm tra SSH key
----------------------------------------

Windows:

C:\Users\<username>\.ssh

Kiểm tra có file:

id_rsa
id_rsa.pub

hoặc

id_ed25519
id_ed25519.pub

----------------------------------------
2. Tạo SSH key (nếu chưa có)
----------------------------------------

ssh-keygen -t ed25519 -C "email@gmail.com"

Nhấn Enter liên tục.

----------------------------------------
3. Add SSH key lên GitHub
----------------------------------------

Copy nội dung:

cat ~/.ssh/id_ed25519.pub

GitHub
→ Settings
→ SSH and GPG Keys
→ New SSH Key
→ Paste

----------------------------------------
4. Kiểm tra kết nối
----------------------------------------

ssh -T git@github.com

Kết quả:

Hi <username>! You've successfully authenticated...

----------------------------------------
5. Clone repository
----------------------------------------

Lấy SSH URL:

git@github.com:username/repository.git

Clone:

git clone git@github.com:username/repository.git

Ví dụ:

git clone git@github.com:davidducanh/git-handbook.git

----------------------------------------
6. Sau khi clone
----------------------------------------

cd repository

git status
